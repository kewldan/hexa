# Hexa Templates для VS Code

Расширение для языка шаблонов структур Hexa (`*.hexpat`, `*.hexa`):

- подсветка синтаксиса (TextMate-грамматика): ключевые слова, примитивные типы,
  `[[атрибуты]]`, `#pragma`/`#include`, числа (hex, binary, octal, разделители `'` и `_`),
  строки, символы, комментарии, размещение `@`;
- языковой сервер `hexa-template-lsp`: диагностика при открытии и правке, автодополнение
  (триггеры `.`, `:`, `[`), подсказки при наведении;
- отладчик `hexa-template-dap`: точки останова по строкам, шаги внутрь/через/наружу,
  продолжение, стек вызовов, переменные (`Locals`, `Fields`, `Position` — текущий `$`).

## Установка

1. Соберите бинарники (из корня репозитория):

   ```sh
   cargo build --release -p hexa-template --bins
   ```

   Получатся `target/release/hexa-template-lsp` и `target/release/hexa-template-dap`.
   Положите их в `PATH` или укажите пути в настройках:

   | Настройка | По умолчанию |
   | --- | --- |
   | `hexaTemplates.serverPath` | `hexa-template-lsp` |
   | `hexaTemplates.debugAdapterPath` | `hexa-template-dap` |
   | `hexaTemplates.trace.server` | `off` (`messages`/`verbose` — журнал LSP) |

   Голое имя ищется в `PATH`, относительный путь отсчитывается от первой папки рабочей
   области, поддерживаются `~` и `${workspaceFolder}`.

2. Соберите и установите расширение:

   ```sh
   cd editors/vscode
   bun install && bun run compile && bunx @vscode/vsce package
   code --install-extension hexa-templates-0.1.0.vsix
   ```

   Для разработки откройте `editors/vscode` в VS Code и запустите «Run Extension» (F5)
   с `bun run watch`.

## Отладка

Без `launch.json`: откройте шаблон и нажмите F5 (или кнопку «Debug Template Against File…»
в заголовке редактора) — расширение спросит файл данных и остановится перед первой
инструкцией. Пример `launch.json`:

```json
{
  "type": "hexa-template",
  "request": "launch",
  "name": "Debug template",
  "template": "${file}",
  "data": "${workspaceFolder}/samples/image.bin",
  "rootType": "Header",
  "offset": 0,
  "stopOnEntry": true
}
```

| Атрибут | Обязателен | Описание |
| --- | --- | --- |
| `template` | да | путь к шаблону (диалект по расширению: `.bt` — 010 Editor, `.h`/`.hpp` — C) |
| `data` | да | файл, к которому применяется шаблон |
| `rootType` | нет | тип, который разбирается с начального смещения вместо верхнеуровневых инструкций |
| `offset` | нет | начальное смещение в файле данных |
| `stopOnEntry` | нет | остановиться перед первой инструкцией |

Относительные пути расширение разворачивает от папки рабочей области; несохранённый шаблон
сохраняется перед запуском.

## Ограничения

- Сервер синхронизирует документ целиком и не поддерживает переход к определению, ссылки,
  символы документа и форматирование.
- Расширение регистрирует только `.hexpat`/`.hexa`; файлы `.bt`, `.h` и `.ksy` сервер понимает,
  но расширение их не привязывает, чтобы не конфликтовать с другими языками.
- Отладчик не поддерживает `pause`, условные точки останова, `evaluate` и вложенные переменные;
  каждая остановка пересчитывает шаблон с начала (вычисление детерминировано).
- Kaitai-спецификации (`.ksy`) отлаживать нельзя.
